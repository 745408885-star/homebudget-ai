# V2 目标用户流程（Phase 6A 设计）

> 当前 React 页面仍运行旧三步流程。本文件描述产品审核通过后才实施的五步目标流程。

```mermaid
flowchart TD
    A["首页"] --> B["Step 1 房屋和房间"]
    B --> C["自动生成默认房间"]
    C --> D["用户可调整房间"]
    D --> E["Step 2 家庭情况"]
    E --> F["Step 3 生活习惯与偏好"]
    F --> G["Step 4 已有物品与明确选择"]
    G --> H["Step 5 家居置办总预算"]
    H --> I{"输入与成员计数校验"}
    I -- "失败" --> H
    I -- "通过" --> J["未来 POST /api/v2/budget/calculate"]
    J --> K["需求识别与排除"]
    K --> L["数量和规格推断"]
    L --> M["预算优化与守恒校验"]
    M --> N["单一采购预算结果"]
```

结果页展示分类汇总、数量、规格、价格区间、当前分配、原因、城市价格说明，以及已有/排除/延后项目。结果页不得展示硬装项目、理想方案或增加预算建议。

V2 API 路径尚未定稿，当前 `/api/budget/calculate` 和旧页面保持不变。
